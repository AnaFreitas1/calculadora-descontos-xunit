# \# Calculadora de Descontos - Testes Parametrizados com xUnit

# 

# Projeto desenvolvido para a disciplina de Garantia e Gestão da Qualidade de Software.

# 

# \## Diferença entre \[Fact] e \[Theory] no xUnit

# 

# \* \*\[Fact]\*: Utilizado para testes unitários individuais que não recebem parâmetros. Valida um único cenário fixo.

# \* \*\[Theory]\*: Utilizado para testes parametrizados. Permite executar o mesmo método de teste múltiplas vezes passando conjuntos de dados variados através do atributo \[InlineData(...)].

# 

# \## Como Executar os Testes

# 

# Para rodar a suíte de testes unitários, execute o comando abaixo na raiz da solução:

# 

# ```bash

# dotnet test

# ```
